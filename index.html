LINGUAL: Language-INtegrated GUidance in Active Learning for Medical Image Segmentation WACV 2027

March 2025 to December 2025

Experts fix segmentation masks by typing what is wrong instead of redrawing pixels. An LLM turns each instruction into calls to EXPAND and SHRINK refinement tools.

  • Cuts annotation interaction cost by up to about 25%.
  • Matches or beats manual correction under domain shift and limited supervision.
Paper
How it works
Problem
Medical images have blurry, ambiguous boundaries. Drawing polygons around them is slow and tiring, and bigger regions cost more effort.
Approach
The expert types a short command such as “expand to bottom-right” or “remove small fragments”. GPT-3.5, using in-context examples, turns it into a program. The program calls refinement tools (EXPAND, SHRINK, REMOVE, FILL, SMOOTH) that edit the mask with no further human input.
Why it scales
The typed command stays about the same length whether the region is small or large, so expert effort stays nearly flat.
Data
Abdominal MRI (CHAOS, in-phase to out-of-phase: liver, kidneys, spleen) and breast ultrasound (BUSI to UDIAT).
83.4%less annotation time, MRI
79.9%less annotation time, ultrasound

ODES: Online Domain Adaptation with Expert Guidance for Medical Image Segmentation MICCAI 2025

July 2023 to June 2024

Source-free, single-pass online domain adaptation for medical image segmentation. It asks an expert only about the images that matter and stores nothing extra.

  • Image pruning plus a diversity-aware rule decide which images get labeled.
  • +7.7% on average over test-time adaptation across several medical datasets.
Paper Project page Code
How it works
Problem
A model trained on one scanner drops in accuracy on another. Hospitals receive patients one after another, so the model must adapt online, with no access to the source data and no stored labels.
Approach
For each incoming batch the model predicts, then image pruning uses batch-norm statistics to keep only the most shifted images. An acquisition rule combines uncertainty, regional impurity, and spatial and feature diversity to pick small patches for the expert. The model updates once and moves on.
Practical fit
Expert labeling happens in the turnover time between patients, so it does not slow the clinical workflow.
Data
Three shifts: CHAOS MRI in-phase to out-of-phase, CHAOS T2-SPIR to DUKE, and prostate MRI from BMC to RUNMC.
+7.7%average gain over test-time adaptation
1 passper batch, no data stored

DEGAST3D: Learning Deformable 3D Graph Similarity to Track Plant Cells in Unregistered Time Lapse Images IEEE TCBB 2025

June 2021 to June 2022

A deformable 3D graph neural network that tracks densely packed plant cells in unregistered time-lapse microscopy.

  • +6.40% F1 over the previous best for tracking.
  • 3D registration and division detection: +14.78% F1 over 2D methods.
Paper Project page Code
How it works
Problem
Plant tissue in 3D microscopy has many tightly packed cells, uneven growth, divisions in different planes, and noisy deep layers. The stacks are also unregistered between time points.
Approach
Cells are segmented in 3D, then each pair of time points is registered with RANSAC on point-cloud features. A graph neural network compares each cell’s local 3D neighbor graph to find its match. A separate 3D CNN checks mother and daughter cell shapes to detect divisions.
Data
Public confocal time-lapse stacks of the Arabidopsis shoot apical meristem, with 4 hours between time points.
+6.83%precision, cell matching
+5.96%recall, cell matching
+15.38%recall, division detection

Uncertainty Quantification for 3D Vision-Language Models

August 2026 to present

A training-free method that links each word of a generated CT report to the parts of the scan that support or contradict it.

  • Occludes blocks of a 3D ViT token grid to measure how each region changes each word.
  • Pools the evidence into word-level and scan-level uncertainty, then marks a small 3D region for a radiologist to review first.
  • Runs on 900+ CT volumes from AbdomenAtlas 3.0 with NV-Reason-CT on a SLURM GPU cluster.
How it works
Problem
A 3D vision-language model can write a fluent CT report that is wrong in places. Radiologists need to know which words to doubt and where to look.
Approach
Block-wise feature replacement (occlusion) on the 3D ViT token grid measures how each scan region supports or contradicts each generated word. An evidential framework pools this into word-level vacuity and dissonance, then into a scan-level uncertainty map.
Output
A budgeted 3D review region that points the radiologist at the most conflicting anatomy, shown as NIfTI overlays in 3D Slicer.
Evaluation
A label-free protocol with clinically grounded error labels.
900+CT volumes, AbdomenAtlas 3.0
0extra training needed

Vision-Language Models for Automated Radiology Report Generation

January 2026 to May 2026

Fine-tuned LLaVA-Med 1.5 on MIMIC-CXR to write chest X-ray reports tied to image evidence.

  • Multi-GPU training with supervised fine-tuning and preference optimization (DPO, GRPO).
  • Image-grounded reasoning reduces hallucinated findings and improves spatial accuracy.
How it works
Model
LLaVA-Med 1.5, a vision-language model for medical images.
Training
Supervised fine-tuning, then preference optimization with DPO and GRPO, on multiple GPUs.
Grounding
Generation is tied to image evidence, which cuts hallucinated findings and improves spatial accuracy over raw-image baselines.
Data
MIMIC-CXR chest X-rays and reports.

Synthesis of Style-Specific Dance by Learning Body Gestures from Music Multimedia Tools and Applications 2025

January 2019 to July 2020

A model that listens to music and generates a matching dance, first as a stick figure and then as realistic video.

  • A CNN-LSTM mixture density network predicts rhythm-aligned poses from the music.
  • A Pix2pixHD GAN renders each pose as a photo-realistic frame.
  • Learns Ballet, Rumba, Cha-Cha, Tango, and Waltz, and beats existing methods on standard metrics.
Paper Video
How it works
Problem
Dance moves fast, and body parts must stay coherent across frames. The model has to learn this from limited audio and motion data.
Approach
A short-time Fourier transform turns the music into features. A CNN and an LSTM read them along with recent poses, and a mixture density network predicts the next pose as a stick figure. A Pix2pixHD GAN with post-processing then renders a realistic dancer.
Styles
Ballet, Rumba, Cha-Cha, Tango, and Waltz.
Data
YouTube dance videos and motion-capture recordings.
